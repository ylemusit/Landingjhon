## 4. Cómo trabajamos

1. **Primera consulta:** el cliente explica la necesidad y la ubicación.
2. **Valoración:** se revisan el acceso, las condiciones y el alcance.
3. **Propuesta:** se detallan trabajos, materiales, precio, plazos estimados y condiciones.
4. **Ejecución:** se dimensiona el equipo y se protege la zona de trabajo.
5. **Entrega:** se revisa el resultado y se documentan los trabajos realizados.
